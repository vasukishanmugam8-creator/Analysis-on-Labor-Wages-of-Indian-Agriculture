# Analysis-on-Labor-Wages-of-Indian-Agriculture
# 🌾 Agricultural Labour Wages Analysis in India (2010–2020)

## 📌 Project Overview

This project analyzes **Agricultural Labour Wages in India** from **2010 to 2020** using **Python, Pandas, Matplotlib, Seaborn, and Power BI**. The objective is to understand wage trends, regional disparities, labour category differences, gender-based wage patterns, and geographical distribution of agricultural wages.

The project includes data cleaning, exploratory data analysis (EDA), interactive visualizations, and a Power BI dashboard to generate meaningful insights for decision-making.

---

## 🎯 Objectives

- Perform Exploratory Data Analysis (EDA) on agricultural labour wage data.
- Clean and preprocess the dataset for analysis.
- Identify trends, patterns, and wage disparities.
- Compare wages across states, labour categories, and gender.
- Develop an interactive Power BI dashboard.
- Provide actionable business insights and recommendations.

## 🔍 Key Insights

- Agricultural wages steadily increased between 2010 and 2020.
- Kerala recorded the highest average agricultural wages.
- Significant wage disparities exist across Indian states.
- Labour category influences wage levels.
- Male workers earned higher average wages than female workers.
- Monthly and annual wages are strongly correlated.
- Geographical location alone does not determine wage levels.
